# 博客交互 HTML 生成规则

以同目录 `template.html` 为骨架，生成指定主题的完整交互 HTML。具体图解部署在 media.ovovk.com，公共适配代码由当前 Nuxt 项目提供。

## 必须保留的部分

1. 保留 head 中完整的 `script[data-blog-embed-loader]`。它只负责接收父页面下发的公共资源，不承担图解业务。
2. 所有可见内容放进唯一的 `.blog-widget` 容器，可附加本图自己的 class。
3. 专属 CSS 写在本图 style 中，业务脚本放在 body 尾部。
4. 不引用 `./embed.css` 或 `./embed.js`，不写死博客前端域名，也不依赖 document.referrer。
5. 不添加主题切换按钮、主题存储、父页面 DOM 访问或另一套高度适配逻辑。

## 配色与布局

- 使用 `public/blog-embed/embed.css` 中定义的 `--embed-*` 变量。可阅读该文件了解全部颜色；不要修改公共文件来适配某一张图。
- 保留合理的 CSS var() 默认值，用于单独打开时的基础浅色预览。例如 `color: var(--embed-text, #0f172a)`。
- 常用变量：`--embed-text`、`--embed-muted`、`--embed-bg`、`--embed-surface`、`--embed-surface-subtle`、`--embed-border`、`--embed-border-strong`、`--embed-accent`、`--embed-accent-text`、`--embed-success`、`--embed-warning`、`--embed-error`。
- SVG fill、stroke 也使用这些变量；Canvas 在读取当前颜色后绘制，并监听 window 的 `blog-embed:themechange` 事件重绘。
- 外层由内容自然撑高，避免固定高度、min-height: 100vh 或依赖 iframe 视口高度的布局。
- 使用 SVG viewBox 等可缩放布局，较宽的图解可放在局部横向滚动容器里。按钮应换行，文字和代码合理换行。
- 所有按钮指定 type="button"；保留可见文字、键盘焦点样式；图解 SVG 提供 aria-label。
- 当前文章页将高度限制在 120～3000px，公共适配器会为超长图解保留纵向滚动。优先使用步骤切换、折叠等方式控制长度。

## 完成前检查

1. 没有固定博客域名，没有请求远程 HTML 同目录的公共适配文件。
2. 在新版文章页的 sandbox="allow-scripts" iframe 中检查明暗来回切换。
3. 检查 320px、768px 及桌面宽度，确认没有页面级横向溢出。
4. 检查步骤切换、说明展开和动画等操作后的高度同步。
5. 重复接收资源消息不会重复安装 style、script 或事件监听。
6. 单独打开时保留基础浅色预览，输出完整 HTML，并保留用户指定的文件名。

## 生成提示词示例

请阅读 docs/blog-widgets/生成规则.md，以同目录 template.html 为骨架，生成演示【主题】的博客交互图，保存为【文件名.html】。保留父页面资源加载器，只实现本图的内容、样式和交互。该 HTML 将独立上传到 media.ovovk.com/blog/，公共适配代码由前端项目下发。
